# PenMods Manager 0.1.0

Windows 上的有道点读笔管理工具：USB 与 Wi-Fi 双通道连接，一键部署 PenMods、装插件、跑 OTA 迁移，全程图形界面。

> 这是社区第三方工具，与网易有道公司没有任何关系。它会以 root 权限修改笔上的文件，请先读完下面「⚠️ 风险提示」再下载。

## 本次发布内容

| 资产 | 说明 |
| --- | --- |
| `PenModsManager-0.1.0-win64.zip` | Windows 10/11 x64 免安装包，解压即用（70 MB，已内置 `adb.exe`） |

仓库里另有：`src/`（Python + QML + C 核心源码）、`plugins/`（8 个可安装插件包 + 校验和 + 审计报告）、`docs/`（设计文档、协议、截图）。

## 功能

- **两种连接**：USB（ADB）即插即用；Wi-Fi（SSH）可在 ADB 侧一键部署公钥，之后拔线也能用。
- **设备信息**：型号、固件、内核、存储占用、运行时间、PenMods 状态、启动配置（ADB 自启 / SSH 自启 / 跳过 ADB 鉴权）。
- **安装 PenMods**：本体必装，播放器 / MathJax / PP-OCR 按需勾选；下载后校验 SHA256 再落盘。
- **V2.7.3 启动器迁移**：识别 2.7.0 / 2.7.1 的冷启动缺陷，引导跑官方完整迁移包，并在迁移后校验 `launcher_ready`。
- **插件**：本地 zip 直接装、在线装、启用/停用；市场页支持索引 URL 与 GitHub 仓库链接。
- **文件 / 终端 / OTA**：设备文件浏览与拖拽传输、设备 shell、应用重启、旧设备 OTA 回滚。
- **界面**：液态玻璃风格，浅色/深色、7 种强调色、10 张内置壁纸；首次启动有免责声明（读完才可确认）。

## 系统要求

- Windows 10 19045 及以上 / Windows 11，x64
- 笔端开启「ADB 调试」，USB 数据线（Wi-Fi 模式需笔已连上和电脑同一网段）
- 支持的笔型：YDP02x（2.0.7 / 2.0.8）、YDPG3（1.0.2 / 1.0.3）；YDP03x 为实验性支持

## 安装

1. 解压 `PenModsManager-0.1.0-win64.zip` 到任意目录（不要放在中文路径或只读目录下）。
2. 双击 `PenModsManager.exe`。
3. 首次启动会弹出免责声明，滚到底部点「我已阅读并同意」。
4. 「连接」页插上笔 → 自动扫描 → 点「连接」。

安装包校验：

```
文件大小  70,135,472 字节
SHA-256   5e3ba8dbb684138bc76cec6c4e745e29827ba42360669ed56adf5bdfc8cbd033
```

> 提示：如果连接页显示「找不到 adb.exe」或「adb 服务异常」，多半是系统临时目录不可写或 5037 端口被占用；程序已把 adb 的 `TMP/TEMP` 指到自己的数据目录，仍失败时在命令行跑 `adb kill-server` 再 `adb devices -l` 看真实报错。

## ⚠️ 风险提示（务必阅读）

**关于本工具本身**

- 安装/更新 PenMods 会**以 root 权限**替换启动脚本、注入或替换动态库、改动系统分区。操作不当、意外断电或版本不匹配可能导致**设备变砖、功能异常、数据丢失、保修失效**，且部分后果不可逆。
- 建议：电量 > 50%、全程不拔线、先备份 `/userdata` 与 `/userdisk`、失败时按 [doc/RECOVERY_2.7.3.md](https://github.com/Lyrecoul/PenMods/blob/main/doc/RECOVERY_2.7.3.md) 恢复。
- **从 PenMods 2.7.0 / 2.7.1 升级必须先跑 V2.7.3 完整迁移包**：只在更新中心升 core 或只换 `.so` 修不好独立启动器，可能反复整机重启或被固件切回原厂。管理器会在安装页给出红色横幅引导。
- 本软件按「现状」提供，不附带任何明示或暗示的担保；作者与贡献者不对设备损坏、数据丢失、保修失效、账号问题承担责任。

**关于插件（重点）**

插件在笔上**与 PenMods 主进程同进程运行、以 root 身份执行、没有任何沙箱**。装错一个插件，等价于把设备控制权交出去。

- 只安装你能确认来源的插件；安装前先用「插件 → 本地 zip」查看包内文件与 `metadata.json`。
- 管理器校验的 SHA256 只能证明「文件没被半路篡改」，**不能证明内容安全**。
- 本仓库发布的 8 个插件包都是第三方作品，**未经逐行审计**；仓库里的 `plugins/SECURITY-AUDIT.md` 是一次静态检查记录，供参考，不构成安全保证。

各插件的行为特点与**使用建议**（事实来自上述审计报告）：

| 插件 | 包名 | 使用建议 | 需要知道的行为 |
| --- | --- | --- | --- |
| 番茄小说 | `fanqie_plugin.zip` | **建议谨慎使用** | 通过明文 HTTP 直连裸 IP `101.35.133.34:5000` 传输内容，网络链路上的第三方可以观察传输内容与账号信息 |
| 哔哩哔哩 | `bili_plugin.zip` | **建议谨慎使用** | 会拉起本地 8000 / 8666 端口且不做鉴权，自动处理极验验证，登录 cookie 以明文保存 |
| 文本编辑器 | `texteditor.zip` | **建议留意** | 可以读写设备上任意路径的文件，误操作会波及系统文件 |
| 浏览器 | `browser.zip` | **建议留意** | 可以读取本地文件；打开的网页内容不由本工具控制 |
| 天气 | `weather.zip` | **建议留意** | 查询定位城市时会把公网出口 IP 交给第三方（B 站接口） |
| 计算器 | `calculator.zip` | 一般使用即可 | 表达式求值有白名单限制，未发现越权行为 |
| 2048 / 扫雷 | `2048.zip`、`minesweeper.zip` | 一般使用即可 | 纯本地逻辑，不联网 |

- **`shell_plugin`（root 终端）不随本仓库发布**：它等于把设备 root shell 直接交出去。需要时请自行侧载，并自行承担相应风险。
- `chajian_fixed.zip` **不是插件包**（5 个旧包的整合压缩，没有 `metadata.json`），管理器会以 `NO_METADATA` 拒绝安装。

## 已知问题

- 部分笔型的 Wi-Fi（SSH）通道在固件空闲时会被断开，需要重新开热点或保持屏幕唤醒；ADB 通道不受影响。
- 市场默认索引地址尚未指向本仓库（上游索引 404）；请在「市场 → 索引 URL」手动填入可用索引，或直接用「从仓库安装」。
- 界面在 125% / 150% 缩放下自适应，但无边框圆角在 Win10 上是 1-bit 硬裁剪，边缘可能有轻微锯齿。
